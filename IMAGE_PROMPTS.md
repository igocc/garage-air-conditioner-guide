The headings below name the intended source PNG assets. The published page uses visually identical WebP exports with the same basename for faster delivery. Original generated outputs remain in the Codex generation workspace.

All bitmap assets use Codex built-in image generation. They intentionally contain no text, logos, watermarks, ratings, model numbers, or fictional product claims. Interface labels remain in HTML so they stay accessible and editable.
